# What's Cooking? 

A simple recipe-finder prototype that suggests meals based on ingredients you already have.

## Features
- Select available ingredients
- See recipes ranked by how many ingredients you are missing, and also syas which ones you are missing
- Expand each recipe to view ingredients and cooking instructions
- Suprise me button that gives a random recipe
- favourites remain visible throughout refreshes

## Run
Open 'index.html' in any modern browser.

## Test checklist
- Select Eggs, Cheese, and Butter; click Find my recipes; Cheese Omelette should say Ready to cook.
- Select Pasta and Tomatoes; Tomato Pasta should list Garlic and Olive Oil as missing.
- Expand a recipe to view its steps.
- Clear selection; verify no ingredients remain selected.
- Click Find with nothing selected; verify a helpful message appears.
